# Magic Xmas Tree �✨

A magical, interactive particle art experience featuring hand gesture control and mesmerizing transformations. Built with Three.js and MediaPipe for a premium sensory journey through nature-inspired forms.

## ✨ Features

- **High-Performance Particle System**: 45,000 particles with fluid physics and organic motion
- **Hand Gesture Control**: ML-powered hand tracking using MediaPipe for intuitive shape morphing
- **7 Magical Transformations**:
  - 🎄 Christmas Tree - A festive decorated conifer with star topper
  - 🪷 Lotus - Elegant layered petals in peaceful bloom
  - 🦋 Butterfly - Graceful wings with mathematical curves
  - 🐦 Phoenix - Majestic bird with flowing tail feathers
  - 🦌 Deer - Noble creature with branching antlers
  - 🦚 Peacock - Stunning tail fan display
  - ⭐ Star - Brilliant celestial prism
- **Multi-Modal Interaction**:
  - Hand gestures (finger counting)
  - Mouse drag rotation with inertia
  - Double-click/tap to cycle shapes
  - Pinch-to-scale gesture support
- **Premium Visual Effects**:
  - Unreal Bloom post-processing
  - Dynamic color palettes per shape
  - Particle glow and additive blending
  - Smooth morphing animations
- **Ambient Background Music**: Auto-plays on page load for immersive experience
- **Responsive Design**: Optimized for both desktop and mobile devices

## 🎮 How to Use

1. **Launch**: Open `index.html` in a modern browser (Chrome/Edge recommended)

2. **Start Experience**: Click **"START MAGICAL JOURNEY"** to enable camera access

3. **Control with Hand Gestures**:
   - **0 fingers (Fist)**: Christmas Tree 🎄
   - **1 finger**: Lotus 🪷
   - **2 fingers**: Butterfly 🦋
   - **3 fingers**: Phoenix 🐦
   - **4 fingers**: Deer 🦌
   - **5 fingers**: Peacock 🦚
   - **Pinch gesture**: Scale the particles (thumb + index distance)

4. **Alternative Controls**:
   - **Double-click/Double-tap**: Cycle through all shapes
   - **Mouse drag**: Rotate the particle system with inertia

5. **Camera Preview**: Small preview window (bottom-right) shows your hand tracking

> 💡 **Tip**: Background music will auto-play when you first interact with the page

## 🛠️ Technology Stack

- **[Three.js](https://threejs.org/)** - 3D rendering engine with WebGL
- **[MediaPipe Hands](https://google.github.io/mediapipe/solutions/hands.html)** - Real-time hand tracking ML model
- **Post-Processing**: EffectComposer with UnrealBloomPass for ethereal glow
- **Vanilla JavaScript & CSS** - No framework dependencies
- **Google Fonts**: Outfit & Playfair Display for premium typography
